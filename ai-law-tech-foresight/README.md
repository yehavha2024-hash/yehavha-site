# AI 법·기술 선제연구 아카이브

기존 `legal-knowledge/`의 전문 법률지식 아카이브와 별도의 독립 연구 프로젝트입니다.

## 목적

기술이 등장한 뒤 법이 뒤따라가는 것이 아니라, 기술의 발전단계를 먼저 추적하고 발생 가능한 법률문제와 법적 공백을 선제적으로 연구하여 정책·거버넌스·입법대안까지 준비합니다.

## 기본 연구 흐름

`기술 → 현행법 → 법적 쟁점 → 기존 법리 적용 가능성 → 법적 공백 → 비교법 → 정책 → 거버넌스 → 입법대안`

## 초기 기술 연구축

1. 인공지능 기본개념
2. 머신러닝
3. 생성형 AI
4. LLM
5. AI Agent
6. Agentic AI
7. Multi-Agent System
8. Physical AI
9. 자율주행
10. 로봇·휴머노이드
11. 인간-AI 결합
12. Transhumanism
13. AGI
14. ASI

AGI·ASI 및 장기 기술전망은 사실로 단정하지 않고 `기술예측·시나리오`로 구분합니다.

## 법률 횡단 연구축

인공지능법, 민사책임법, 제조물책임법, 소프트웨어법, 개인정보·데이터법, 저작권법, 지식재산법, 자율주행자동차법, 로봇법, 보험법, 회사법·법인론, 증명책임·소송법을 기술별로 교차 연결합니다.

## 비교법

대한민국, EU, 미국, 영국, 일본, 중국 및 기타 주요 국가의 자료를 `법률 / 정책 / 규제 / 가이드라인 / 입법안 / 판례 / 학술논의`로 분류합니다. 해외 판례는 사실관계·쟁점·판단·법리·AI법적 의미까지 분석하는 것을 원칙으로 합니다.

## 법적 공백과 해결

행위귀속, 책임귀속, 인과관계, 예견가능성, 다중 에이전트 책임분산, 창발적 손해, 증명곤란, 로그 접근, 설명가능성, 책임재산, 보험, 기능적 법적 지위 등을 추적합니다. 문제 제기에 그치지 않고 현행법 해석, 법률 개정, 특별법, 등록제도, 책임관리인, 로그보존, 보험·공탁, 책임재산, 증명책임 조정, 기능적 단위의 법적 지위, 제한적 소송상 지위 등 가능한 해결수단을 연결합니다.

## 박사논문 연결

모든 기술 연구자료에는 `행위효과 / 책임귀속 / Agentic AI / Multi-Agent / 창발적 손해 / 계층적 책임귀속 / 증명위험 / 기능적 단위 / 입법론` 태그를 부여할 수 있습니다.

석사논문은 공식 공개 URL이 확인되기 전까지 임의 링크를 만들지 않습니다. 공개 후 `석사논문 → 후속 연구 → Agentic AI → Multi-Agent AI → 박사논문 연구` 흐름으로 연결합니다.

## Cloudflare Pages 배포 예정 설정

- Repository: `yehavha2024-hash/yehavha-site`
- Production branch: `main`
- Root directory: `ai-law-tech-foresight`
- Framework preset: None
- Build command: 현재 Nexus와 동일한 정적 HTML 설정 사용
- Build output directory: `.`
- 권장 프로젝트 이름: `yehavha-ai-foresight`

현재 `nexus.project.json`은 `publish: false`입니다. 실제 Pages URL이 확정된 뒤 URL을 확인하고 `publish: true`로 바꾸면 YEHAVHA Nexus 자동화가 새 연구 프로젝트를 메인 포털에 자동 등록합니다.
