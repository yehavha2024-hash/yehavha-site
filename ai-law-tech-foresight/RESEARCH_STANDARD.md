# AI 법·기술 선제연구 아카이브 연구표준

기준일: 2026-08-07

## 1. 기술 연구노트 표준

모든 기술 연구노트는 다음 9단계를 기본구조로 한다.

1. 기술적 정의와 작동구조
2. 현행법 규율
3. 법적 쟁점
4. 학설·기존법리
5. 법적 공백
6. 비교법·해외사례
7. 책임·증명구조
8. 정책대안
9. 입법론

각 항목은 단순 키워드 목록으로 끝내지 않고 본문형 서술로 작성한다. 기술이 어떤 방식으로 작동하기 때문에 어떤 법적 문제가 발생하는지 인과관계를 설명하고, 현행법이 해결할 수 있는 범위와 한계를 구별한다.

법적 공백을 적은 경우에는 반드시 하나 이상의 현실적인 해결방향을 함께 제시한다. 정책 또는 입법대안은 해결하려는 위험, 적용대상과 의무주체, 집행·증명 방법, 예상되는 반론과 부작용을 함께 검토한다.

## 2. 학술 서술 원칙

- 기술설명과 법률평가를 분리한 뒤 다시 연결한다.
- 법률의 존재만 나열하지 않고 해당 기술의 어느 기능에 어떤 규범이 적용되는지 설명한다.
- 판례가 없는 신설기술에는 판례를 만들어 넣지 않는다.
- 직접 판례가 부족하면 시행령·고시·공식 가이드라인·인접 판례·비교법을 구별하여 사용한다.
- 규제법 위반과 민사상 손해배상책임은 자동으로 동일시하지 않는다.
- 피해자 보상, 최종 책임귀속, 보험·구상관계를 서로 구별한다.
- 기술적 불투명성을 곧바로 면책사유로 보지 않고 정보지배·통제가능성·증거편재를 검토한다.

## 3. 기술예측·시나리오 표시

AGI, ASI, Transhumanism 등 실현시기·성능·사회적 파급이 확정되지 않은 내용은 `기술예측·시나리오`로 명시한다.

- 예상 연도는 사실처럼 단정하지 않는다.
- 전문가·기업·연구기관의 전망은 전망자료로만 기록한다.
- 현재 확인된 기술능력과 미래 시나리오를 같은 문단에서 혼합하지 않는다.
- 법적 연구는 특정 시기가 아니라 능력·자율성·위험 임계값을 중심으로 설계한다.
- 미래 시나리오를 근거로 현존하는 저위험 기술 전체에 동일한 규제를 정당화하지 않는다.

## 4. 법률 연구축

각 기술은 하나의 법률에만 귀속시키지 않고 관련 법률을 횡단 연결한다.

`인공지능법 / 민사책임법 / 제조물책임법 / 소프트웨어법 / 개인정보·데이터법 / 저작권법 / 지식재산법 / 자율주행자동차법 / 로봇법 / 보험법 / 회사법·법인론 / 증명책임·소송법`

각 연구노트에서 일반법과 특별법, 공법상 규제와 사법상 책임, 사전 안전규제와 사후 손해배상을 구별한다.

## 5. 비교법 자료구분

국가별 자료는 반드시 다음 유형 중 하나로 구분한다.

`법률 / 정책 / 규제 / 가이드라인 / 입법안 / 판례 / 학술논의`

해외 자료는 한국법의 직접 법원으로 취급하지 않고 비교법·입법론·주의의무 구체화의 자료로 구별한다. 법률, 자율규범, 행정가이드라인의 구속력 차이를 명시한다.

## 6. 해외 판례·사례 분석표준

해외 판례를 등록할 때는 최소한 다음 항목을 작성한다.

1. 국가·법원·선고일·사건번호
2. 사실관계
3. 법적 쟁점
4. 법원의 판단
5. 법원의 논증
6. 핵심 법리
7. 관련 선행·후속 판례
8. 해당 국가 AI 법제에서의 의미
9. 한국 현행법과의 비교
10. AI 기술·법적 공백·박사논문 태그

판례번호만 나열하지 않는다. 원문을 확인하지 않은 판례는 `원문 검증 완료`로 표시하지 않는다. 행정기관의 사고보고·가이드라인·집행사례는 판례와 별도 유형으로 표시한다.

## 7. 책임·증명구조 연구표준

책임분석은 원칙적으로 다음 순서를 따른다.

`기능단위 특정 → 개발자·공급자·통합자·배치자·운영자·인간감독자 구분 → 각 주체의 통제가능성 → 구체적 주의의무 또는 법정의무 → 위반·결함 → 인과관계 → 피해 → 공동책임·구상`

증명분석에는 최소한 다음 자료를 검토한다.

- 모델·소프트웨어·하드웨어 버전
- 입력·출력·도구호출·센서·제어 로그
- 데이터 출처와 변경이력
- 위험평가·테스트·레드팀·모니터링 기록
- 인간의 승인·거절·수정·중단 기록
- 사고 전후 업데이트와 경고
- 사업자간 계약상 역할과 실제 기술적 통제권

정보가 특정 사업자에게 편재되어 있거나 법정·합리적 보존의무를 위반하여 자료가 소실된 경우 문서제출, 증명방해, 증명책임 조정 가능성을 별도로 검토한다.

## 8. 법적 공백 연구표준

법적 공백은 다음 순서로 작성한다.

`문제 → 기존 법리 → 적용 가능한 범위 → 적용 한계 → 증거·증명 문제 → 가능한 해결수단 → 부작용·반론 → 권고안`

주요 공백분야는 행위귀속, 책임귀속, 인과관계, 예견가능성, 다중 에이전트 책임분산, 창발적 손해, 증명곤란, 로그 접근, 설명가능성, 책임재산, 보험, 기능적 법적 지위이다.

## 9. 정책·입법 제안 표준

정책 또는 입법안은 다음 요소를 함께 검토한다.

- 해결하려는 위험
- 적용 대상과 의무주체
- 위험수준에 따른 규제강도
- 집행·감독·증명 방법
- 개인정보·영업비밀과 증거접근의 조정
- 과잉규제·책임회피·혁신저해 등 부작용

가능한 수단은 현행법 해석, 기존 법률 개정, 특별법, 등록, 책임관리인, 로그보존, 보험, 공탁, 책임재산, 증명책임 조정, 기능적 단위의 법적 지위, 제한적 소송상 지위 등이다.

## 10. 박사논문 태그

모든 자료는 필요한 경우 다음 태그를 부여한다.

`행위효과 / 책임귀속 / Agentic AI / Multi-Agent / 창발적 손해 / 계층적 책임귀속 / 증명위험 / 기능적 단위 / 입법론`

자료 작성단계에서부터 태그를 부여하여 박사논문의 장·절·사례·비교법 자료로 다시 검색할 수 있게 한다.

## 11. 석사논문 연결

석사논문 공개 전에는 임의의 다운로드 주소나 비공식 사본을 연결하지 않는다. 공식 저장소 공개 후 확인된 링크만 등록하고 다음 흐름으로 연결한다.

`석사논문 → 후속 연구 → Agentic AI → Multi-Agent AI → 박사논문 연구`
