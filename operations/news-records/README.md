# YEHAVHA NEWS 기사 보존 기록

이 디렉터리는 배포 루트인 `nexus/` 밖에 두어 웹사이트 화면과 분리된 운영기록으로 관리한다.

## 보존 원칙
1. 공표된 인터넷신문 보도의 원본 또는 사본은 최소 6개월 보관한다.
2. YEHAVHA NEWS는 삭제보다 이력 보존을 우선하며 Git 기록은 특별한 사유가 없으면 장기 보존한다.
3. 기사 변경 흐름은 다음 항목으로 추적한다.
   - 초고
   - 발행본
   - 수정본
   - 수정일시
   - 수정사유
   - 근거자료
4. 자동 기록은 `articles/<기사ID>/manifest.json`과 커밋별 HTML 스냅샷으로 남긴다.
5. 초고는 공개 전 작성단계 자료이므로 비공개 작업공간에 보관하고 발행 시 해당 초고의 식별자나 저장위치를 manifest의 `draftRef`에 연결한다. 공개 저장소에는 미공개 취재자료나 취재원 개인정보를 넣지 않는다.
6. 주요뉴스 배열은 `arrangement/`에 스냅샷을 남기며 `arrangement/state.json`에서 최초 노출시각, 최근 노출시각, 제거시각과 위치를 추적한다.
7. 정정·반론 요청과 관련된 자료는 사건 종결 전 임의 삭제하지 않는다.

## 수정사유
자동 기록의 기본 수정사유는 해당 Git 커밋 제목이다. 사실관계 정정처럼 구체적 사유가 필요한 경우 커밋 제목에 핵심 사유를 적고 기사 본문에도 수정고지를 표시한다.

## 근거자료
기사 HTML의 `.article-sources` 영역에 있는 외부 링크를 자동 추출해 manifest에 기록한다. 판결문·공문서·보도자료·공식통계 등 링크로 표현하기 어려운 자료는 별도 비공개 자료의 식별자를 `evidenceNotes`에 기록한다.

## 법적 기준
- 「언론중재 및 피해구제 등에 관한 법률」 제15조제8항
- 같은 법 시행령 제9조 및 제11조의2
- 정정·반론 처리 세부기준은 `nexus/news/policies/corrections-replies.html` 참조
