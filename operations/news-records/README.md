# YEHAVHA NEWS 기사 보존 기록

이 디렉터리는 배포 루트인 `nexus/` 밖에 두어 웹사이트 화면과 분리된 운영기록으로 관리한다.

## 보존 원칙
1. 공표된 인터넷신문 보도의 원본 또는 사본은 최소 6개월 보관한다.
2. YEHAVHA NEWS는 삭제보다 이력 보존을 우선하며 Git 기록은 특별한 사유가 없으면 장기 보존한다.
3. 기사 변경 흐름은 다음 항목으로 추적한다.
   - 초고
   - 발행본
   - 수정본
   - 수정일시
   - 수정사유
   - 근거자료
4. 자동 기록은 `articles/<기사ID>/manifest.json`과 커밋별 HTML 스냅샷으로 남긴다.
5. 초고는 공개 전 작성단계 자료이므로 비공개 작업공간에 보관하고 발행 시 해당 초고의 식별자나 저장위치를 manifest의 `draftRef`에 연결한다. 공개 저장소에는 미공개 취재자료나 취재원 개인정보를 넣지 않는다.
6. 주요뉴스 배열은 `arrangement/`에 스냅샷을 남기며 `arrangement/state.json`에서 최초 노출시각, 최근 노출시각, 제거시각과 위치를 추적한다.
7. 정정·반론 요청과 관련된 자료는 사건 종결 전 임의 삭제하지 않는다.


## 공개 수정표시 기준
- 모든 기사에는 최초 발행시각을 `작성 일시`로 표시한다.
- 발행 후 기사 내용이 수정되면 `수정 일시`를 함께 표시한다.
- 오탈자, 표현 정리, 링크·출처 추가, 핵심 의미를 바꾸지 않는 단순 보강은 수정일시만 갱신하고 별도의 공개 고지 셀은 두지 않는다.
- 반론 반영 또는 핵심 사실·제목·리드문·결론·인과관계·전체 맥락이 실질적으로 바뀌는 수정은 리드문 아래, 기사 본문 시작 전에 `주요 수정 고지` 셀을 둔다.
- 주요 수정 고지에는 변경 전, 변경 후, 수정 사유, 수정 일시, 승인 편집자를 기록한다.
- 주요 수정은 편집자 승인이 있어야 공개한다. 공개 마크업은 `data-editor-approved="true"`, `data-editor`, `data-approved-at`을 포함해야 하며 자동 감사에서 이를 확인한다.

## 수정사유
자동 기록의 기본 수정사유는 해당 Git 커밋 제목이다. 사실관계 정정처럼 구체적 사유가 필요한 경우 커밋 제목에 핵심 사유를 적고 기사 본문에도 수정고지를 표시한다.

## 근거자료
기사 HTML의 `.article-sources` 영역에 있는 외부 링크를 자동 추출해 manifest에 기록한다. 판결문·공문서·보도자료·공식통계 등 링크로 표현하기 어려운 자료는 별도 비공개 자료의 식별자를 `evidenceNotes`에 기록한다.

## 관련 YouTube 영상 연결 기준
- 기사와 함께 제공하는 영상은 기사 사건 자체의 공식 영상 또는 주요 언론 보도를 최우선으로 한다.
- 동일 사건의 적절한 영상이 없거나 비공개·삭제·지역제한·품질저하 등으로 사용할 수 없으면, 같은 인물·행사·작품·종목·지역·산업과 직접 연결되는 관련 뉴스 또는 공식 영상을 사용할 수 있다.
- 위 기준에서도 적절한 영상이 없으면 기사 이해에 실질적으로 도움이 되는 배경·해설·인터뷰·현장·절차 영상까지 허용한다. 다만 기사와의 관계를 독자가 바로 이해할 수 있어야 한다.
- 동일 사건 영상이라는 이유만으로 비공개·삭제 가능성이 높거나 출처·제목·채널을 검증하기 어려운 저품질 영상을 억지로 채택하지 않는다.
- 후보가 여럿이면 공식기관·행사 주최자·당사자 공식 채널·주요 언론 등 검증 가능한 출처를 우선한다. 출처 신뢰도가 비슷하면 기사와의 연관성, 시청 가능성, 설명력 순으로 판단한다.
- 채택 전 실제 YouTube 페이지 존재 여부, 11자리 video ID, 제목, 채널명, 공개 상태와 기사 관련성을 확인한다. ID·제목·채널을 추정하거나 조작하지 않는다.
- 기사 HTML의 단일 `article-video-link`를 원소스로 사용하며, 썸네일은 같은 video ID의 YouTube 썸네일을 사용한다. `news-data.js`의 video metadata는 기사 HTML에서 파생한다.
- 기사 사건과 관련된 신뢰할 만한 영상이 전혀 없으면 무관한 영상을 채우지 않고 텍스트 카드 fallback을 유지한다.
