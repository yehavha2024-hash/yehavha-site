# YEHAVHA Nexus 글·연구 아카이브 편집 원칙

## 목적

이 영역은 전자책 판매 페이지와 별개로, 완성된 글을 웹에서 직접 읽을 수 있도록 축적하는 공개 아카이브다. 성경·신학, AI·Suno, 히브리어·언어를 포함해 향후 어떤 주제의 글도 동일한 구조로 추가할 수 있다.

## 기본 구조

각 글은 다음 순서로 정리한다.

1. 제목
2. 부제 또는 한 줄 설명
3. 핵심 요약
4. 본문
5. 필요한 경우 성경 구절·인용·주석
6. 관련 글

## 성경·신학 글 편집 원칙

성경 저자를 현대적 의미의 논증가로 규정하거나, 저자가 독자적으로 철학적 논증을 설계했다는 식으로 서술하지 않는다.

성경은 성령의 영감 아래 사람을 통해 기록된 말씀이라는 신앙적 전제를 존중한다. 따라서 본문의 지혜·지식·통찰이 인간 저자의 독자적 지적 설계만으로 발생한 것처럼 표현하지 않는다.

현재의 연구와 분석이 성경 본문에서 논리적 구조, 상호 연결, 반복되는 패턴 또는 깊은 통찰을 발견하는 경우에는 다음을 구분한다.

- 성경 본문 자체가 말하는 내용
- 성령의 영감에 관한 신앙적 이해
- 현재 연구자가 본문을 비교·분석하여 도출하는 해석과 논증

즉, 현대 연구자가 논증하는 것과 성경 본문이 증언하는 것을 혼동하지 않는다.

## 문장과 화면 원칙

작성 단계에서 사용된 별표, 임시 마크다운 기호, 메모용 표시는 공개 화면에 노출하지 않는다.

본문은 짧은 문단과 명확한 소제목으로 나누되, 지나친 목록화보다 읽는 흐름을 우선한다.

성경 구절은 일반 인용문과 시각적으로 구분하고 장절을 함께 표시한다.

AI·Suno 강의형 글도 전자책 형식으로 만들지 않고, 하나의 독립 글 또는 연재의 한 챕터로 직접 읽을 수 있게 구성한다.

## 데이터 운영

글 목록과 메타데이터는 `articles.json`에서 관리한다.

실제 본문은 `content/<article-id>.json`에 한 글씩 분리하여 저장한다.

새 글을 추가할 때 기존 화면 코드를 복제하지 않고 데이터와 본문 파일만 추가하는 것을 원칙으로 한다.
