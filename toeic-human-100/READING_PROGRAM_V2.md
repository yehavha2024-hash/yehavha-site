# 토익인간 100일 프로젝트 V2 — 장문 독해 중심 학습 규격

## 1. 최종 목표

이 프로젝트의 1차 목표는 TOEIC 점수 자체가 아니라 영어 장문을 끝까지 읽고 문장·문단의 구조와 전체 맥락을 유지하는 독해력을 형성하는 것이다. TOEIC은 어휘·숙어·문법·업무영어·문제유형을 체계적으로 반복하기 위한 실전 훈련틀로 사용한다.

핵심 전환은 다음과 같다.

기존: 어휘 1개 → 숙어 1개 → 문장 1개 → 문법 1개 → 문제 1개

V2: 긴 본문 전체 읽기 → 본문 속 어휘·숙어·문법·구문 분석 → TOEIC 문제 적용 → 같은 본문 재독

## 2. 하루 본문 길이

- DAY 1부터 DAY 100까지 본문 길이를 동일 수준으로 유지한다.
- 기준값: 약 1,500 words
- 허용범위: 1,350~1,650 words
- 학습 후반이라고 본문 길이를 증가시키지 않는다.
- 난이도는 글의 길이가 아니라 문장구조, 정보분산, 추론, 복수문서 연결, 추상도에서 조정한다.
- 하루 본문은 최소 8개 이상의 자연스러운 문단으로 구성한다.

목표는 100일 동안 '이 정도 길이의 영어를 매일 읽는 것' 자체를 정상적인 독서량으로 만드는 것이다.

## 3. 장르 원칙

영어기사 한 종류로 고정하지 않는다. TOEIC이 다루는 상황과 문서유형을 넓게 순환시키되, 영어 원서 독해에 필요한 서술·설명·논증 구조까지 포함한다.

필수 장르군:

- 업무 이메일·답장·후속메일
- 사내공지·정책·절차 안내
- 채용·인사·교육·평가
- 광고·제품소개·고객안내
- 주문·구매·청구·배송·물류
- 예약·호텔·항공·출장·여행
- 회의·행사·세미나·일정표
- 기사·기업뉴스·보도자료
- 업무보고서·조사보고서·설문결과
- 프로젝트 계획·진행상황·변경보고
- 계약·서비스조건·보증·환불정책
- 시설·임대·공사·안전·유지보수
- 은행·보험·결제·재무
- 소매·식당·서비스·고객불만
- IT·소프트웨어·시스템 장애
- 제조·생산·품질관리
- 환경·에너지·사회공헌
- 의료·건강·복지 관련 업무문서
- 인터뷰·리뷰·설명문·비교문
- 원인·결과 분석·사례분석·찬반 논증
- 단일 장문
- 연속 문서
- 이중·삼중 복합문서

100일 전체에서 특정 장르에 편중되지 않도록 분포를 기록한다.

## 4. TOEIC 마스터 커버리지

'기출 모든 단어'는 ETS가 역대 출제어 전체 목록을 공식 단일 파일로 공개하지 않으므로, 확보 가능한 공식 공개문항·공식 학습자료·검증된 TOEIC 어휘자료를 통합해 구축한 프로젝트 마스터 코퍼스 전체를 뜻한다. 실제 기출문제 원문을 무단 복제하지 않고 어휘·구문·문법·출제요소를 추출해 자체 본문에 재구성한다.

마스터 코퍼스는 다음을 별도 항목으로 관리한다.

- lemma / 표제어
- word family / 파생어군
- part of speech / 품사
- TOEIC 핵심 의미
- 다의어 의미
- collocation / 연어
- phrasal verb / 구동사
- idiom / 숙어
- fixed expression / 고정표현
- grammar pattern / 문법 패턴
- sentence structure / 문장구조
- question pattern / 질문유형
- genre / 사용 장르
- exposure days / 노출일
- exposure count / 총 노출횟수

모든 마스터 항목은 100일 본문 또는 문제에서 최소 1회 이상 등장해야 한다.

### 반복노출 기준

- A급 핵심어휘·표현: 8~15회 이상
- B급 중요어휘·표현: 4~8회
- C급 일반 기출·출제어휘: 2~4회
- 저빈도·고난도 항목: 최소 1~2회

동일 단어는 같은 뜻만 반복하지 않고 가능한 경우 서로 다른 문맥·품사·collocation으로 재노출한다.

## 5. 문법 전체 커버리지

문법은 독립 강의가 아니라 장문을 해석하는 도구로 가르친다. 동시에 Part 5·6 문제로 정답 판단능력을 확인한다.

필수축:

- 문장성분과 5형식의 기본 인식
- 명사·대명사·형용사·부사
- 품사 자리 판단
- 동사·수일치·시제
- 능동태·수동태
- 조동사
- to부정사·동명사
- 현재분사·과거분사·분사수식
- 전치사
- 등위·종속접속사
- 관계대명사·관계부사
- 명사절·형용사절·부사절
- 비교급·최상급·동등비교
- 병렬구조
- 가정·조건
- 수량표현
- 대명사 지칭
- 접속부사와 논리표지
- 도치·강조 등 고급 구조
- 동사 어법과 고정결합

## 6. 긴 문장 구조 커버리지

본문에는 다음 구조가 반복적으로 등장해야 한다.

- 긴 주어 + 본동사
- 명사 + 관계절 + 본동사
- 명사 + 분사수식 + 본동사
- 삽입구·동격구가 포함된 문장
- although/while/whereas 대비 구조
- because/since/as 원인 구조
- if/unless/provided 조건 구조
- that/what/whether 명사절
- 수동태 + to부정사
- 완료시제 + 수동태
- 병렬 동사·병렬 명사·병렬 절
- 전치사구가 연속되는 구조
- 하나의 문장에 대비와 원인이 동시에 존재하는 복문
- 앞 문장 전체를 this/which/it이 받는 지칭 구조

핵심 목표는 문법용어 암기가 아니라 '주어·본동사·핵심절·수식덩어리'를 눈으로 분리하는 자동화이다.

## 7. 원서 독해용 추가훈련

TOEIC 정답 찾기만으로는 부족하므로 모든 긴 본문에서 다음을 훈련한다.

- 각 문단의 핵심문장 파악
- 문단 기능: 문제제기·배경·원인·사례·반론·대응·결론
- however/therefore/in addition/for example/in contrast 등 논리표지
- 대명사·지시어의 선행내용 추적
- 앞 문단의 정보를 기억한 상태에서 다음 문단 읽기
- 모르는 단어가 있어도 전체 구조를 유지하고 계속 읽기
- 전체 글을 한국어 한두 문장으로 요약

## 8. 하루 학습 순서

### BLOCK 1 — READ

1. 약 1,500단어 원문을 도움 없이 처음부터 끝까지 읽는다.
2. 모르는 단어 때문에 중단하지 않는다.
3. 첫 독해시간과 체감 이해도를 기록한다.

### BLOCK 2 — ANALYZE & LEARN

1. 전체 내용·문단별 기능 확인
2. 본문 핵심어휘·파생어·다의어 확인
3. 숙어·구동사·collocation 확인
4. 가장 긴 핵심문장 8~12개 구조분석
5. 본문에서 실제 사용된 문법을 설명
6. 같은 본문을 다시 읽는다.

### BLOCK 3 — APPLY & REVIEW

1. Part 5 문법·어휘 문제
2. Part 6 문맥·연결·문장삽입 문제
3. Part 7 목적·세부정보·추론·의도·paraphrase·복수문서 문제
4. 오답 원인 분류
5. 도움 없이 본문 최종 재독
6. 전체 글 한두 문장 요약

사용자에게 보이는 완료 체크는 위 3개 BLOCK만 둔다.

## 9. 오답 분류

- 어휘를 몰랐다
- 숙어·결합을 몰랐다
- 문법을 몰랐다
- 주어·본동사를 못 찾았다
- 긴 수식구조를 잘못 연결했다
- 질문의 뜻을 파악하지 못했다
- 지문에서 근거를 찾지 못했다
- paraphrase를 알아보지 못했다
- 앞 문단의 정보를 잊었다
- 시간 부족
- 추측/찍기

## 10. 검증 기준

100일 콘텐츠 완성 후 자동 감사에서 다음을 검사한다.

- DAY 1~100 누락 0
- 하루 본문 1,350~1,650 words
- 하루 본문 최소 8문단
- 완료축 정확히 3개
- 마스터 어휘 미등장 0
- 마스터 숙어·collocation 미등장 0
- 필수 문법 미등장 0
- 필수 문장구조 미등장 0
- 필수 Part 7 질문유형 미등장 0

- A/B/C 등급별 최소 반복횟수 충족
- 실전문제 정답·해설·본문근거 누락 0
- 실제 공식 기출문제 문장 복제 금지
