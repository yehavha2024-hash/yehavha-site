# 105개 연구카드 법령 최신성 감사 — 2026-08-09

## 감사 원칙

법령의 `시행일`, 연구카드의 `검토일`, 이미 공포되었지만 아직 시행되지 않은 `장래 시행일`을 같은 날짜로 취급하지 않는다.

각 카드에는 다음 정보를 분리한다.

- `lawDate`: 카드가 직접 적용하는 현재 시행 법령의 기준일
- `lawChecked`: 현행법을 다시 대조한 날짜(2026.08.09)
- `currentLawVersions`: 카드와 연결되는 법률의 현재 시행본 정보
- `pendingLawChanges`: 공포되었으나 2026.08.09 현재 아직 시행되지 않은 변경
- `currentnessStatus`: 현행법 대조 / 법령 비의존 / 개별 재확인 대상

## 주요 교정사항

### 신규 핵심 법리 20개

신규 20개는 최초 작성 시 `reviewed: 2026.08.09`와 `lawDate: 2026.08.09`가 함께 들어가 검토일이 법령 시행일처럼 보일 수 있었다.

이를 법률별 실제 시행일로 분리하도록 자동 교정하였다.

대표 예:

- 민법 관련 카드 → 2026.03.17 시행본
- 행정기본법 관련 카드 → 2026.03.19 시행본
- 국가배상법 관련 카드 → 2025.01.07 시행본
- 형법 관련 카드 → 2026.03.12 시행본
- 형사소송법 관련 카드 → 2026.07.01 중심의 조문별 단계시행
- 저작권법 관련 카드 → 2026.05.11 현재 시행본
- 부동산등기법 → 2025.01.31 시행본
