# 법리·판례 연구 / Advanced Legal Studies

예하바 넥서스의 전문 법률지식 프로젝트용 정적 웹페이지입니다.

## 운영 원칙

- 데일리 강제형이 아니라 **주제 단위 누적형**으로 운영합니다.
- 각 연구 항목은 조문·판례·사실관계·논증을 검토한 뒤 공개합니다.
- 모든 항목에 최종 검토일을 기록합니다.
- 법령과 판례는 변경될 수 있으므로 공식 원문을 함께 연결합니다.
- 난도는 입문자가 아니라 변호사시험·법무사·변리사 등 전문 법률영역을 기준으로 합니다.

## 파일

- `index.html` : 화면 구조
- `styles.css` : 디자인
- `data.js` : 연구 콘텐츠 데이터
- `app.js` : 검색·필터·상세보기

## 콘텐츠 추가

`data.js`의 배열에 연구 항목을 추가하면 자동으로 카드와 검색 결과에 반영됩니다.

권장 필드:

- `area`
- `type`
- `title`
- `summary`
- `keywords`
- `reviewed`
- `issue`
- `rule`
- `analysis`
- `research`
- `sources`

## Cloudflare Pages 연결

이 저장소를 Cloudflare Pages에 연결할 경우 프로젝트 루트 디렉터리를 `legal-knowledge`로 지정합니다.
정적 사이트이므로 별도 빌드 명령은 필요하지 않으며 출력 디렉터리는 `.` 로 설정할 수 있습니다.

배포 후 생성된 `pages.dev` 주소를 예하바 넥서스의 `연구·지식` 카테고리에 연결합니다.
