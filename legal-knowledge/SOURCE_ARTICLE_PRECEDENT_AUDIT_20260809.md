# 105개 연구카드 출처·조문·판례 인용강도 감사 — 2026-08-09

## 1. 목적

105개 전체 연구카드를 대상으로 다음 세 축을 독립적으로 관리한다.

1. 출처 링크의 공식성·직접성·안정성
2. 인용 조문번호와 카드의 법적 주장 사이의 정확성
3. 판례가 해당 카드의 법리를 직접 판시하는 정도

단순히 링크가 존재하거나 판례 사건번호가 적혀 있다는 이유로 고품질 인용으로 평가하지 않는다. 법률 연구자료에서는 `공식 1차 출처인지`, `해당 조문을 직접 가리키는지`, `판결의 ratio가 카드의 주장과 실제로 일치하는지`를 구별한다.

## 2. 출처 링크 등급

### A1 — 공식 직접출처

- 국가법령정보센터의 개별 조문 직접경로
- 국가법령정보센터의 개별 판례 `precInfoP` 직접경로
- 국가법령정보센터 행정규칙 직접경로

법률 주장·판례 인용에 가장 우선한다.

### A2 — 공식 기관·법령 페이지

- 국가법령정보센터 법률 전체·연혁 페이지
- 사법정보공개포털
- 정부부처·공공기관 `.go.kr`
- NIA 등 공식 공공기관
- EUR-Lex·EDPB 등 EU 공식 기관
- NHTSA·FAA·FDA·USPTO·U.S. Copyright Office 등 미국 정부기관
- WIPO·OECD 등 국제기구

공식성은 높지만 특정 조문·판례의 직접 고정링크보다 인용 정밀도는 한 단계 낮다.

### B1 — 공식이나 경로 안정성이 낮은 출처

- 법원 `NewsViewAction`, `DcNewsViewAction` 계열
- 국가법령정보센터 판례검색·관련자료 검색 페이지
- 웹방화벽·리디렉션·검색조건에 영향을 받을 수 있는 공식 URL

내용의 권위는 공식 1차 자료이나 장기 링크 안정성 때문에 A1/A2 직접경로로 교체를 권장한다.

### C — 보조·2차 출처

학술논문, 출판사, SSRN 등. 법리 해석·비교연구에는 유용하지만 법령·판례 자체의 존재와 문언을 증명하는 1차 출처로 사용하지 않는다.

### D — 오류

URL 형식 오류, 비웹 링크, 명백히 잘못 연결된 출처. 발견 즉시 수정대상이다.

### N — 특정 출처 비의존

법적 추론·방법론처럼 특정 법령·판례 링크의 완결성이 연구노트의 핵심 품질기준이 아닌 경우에 한한다.

## 3. 조문번호 정확성 등급

### A — 수동·공식 대조 완료

국가법령정보센터의 현행 조문 또는 해당 판례가 직접 참조한 조문과 2026-08-09 기준 개별 대조하였다.

### A- — 직접 조문경로 연결

조문번호와 국가법령정보센터 직접 조문링크가 연결되어 있다. 다만 카드의 구체적 사실에 그 조문이 어떻게 적용되는지는 별도의 법률해석 문제다.

### B+ — 조문번호는 특정되어 있으나 법률 전체·연혁 링크

조문번호 자체는 카드에 명시되어 있으나 링크가 개별 조문 고정경로가 아니라 법률 전체 페이지다. 조문 직접링크로 보강할 가치가 있다.

### B — 공식 법률근거는 있으나 특정 조문 직접성이 낮음

복수 조문·기본법·정책법을 넓게 다루는 연구노트에서는 허용할 수 있으나 실제 사건 적용 전에는 조문을 특정해야 한다.

### C — 개별 재확인 필요

공식 조문출처가 없거나 조문번호와 법률효과의 대응을 다시 대조해야 하는 카드다.

### N — 특정 조문 비의존

법적 추론·방법론 카드에 적용한다.

## 4. 판례 인용강도 등급

### P1 — 대법원·헌법재판소 직접 판시

카드의 핵심 법리가 대법원 또는 헌법재판소 판결·결정의 직접 쟁점이고 원문대조가 완료된 경우다. 사실관계와 판시범위의 한계를 함께 기록한다.

### P2 — 전문법원·하급심 직접 판시

특허법원 등 전문법원 또는 하급심 판결이 카드의 핵심 쟁점을 직접 판단한 경우다. 상급심 판례와 동일한 권위로 표시하지 않는다.

### P3+ — 대법원·헌재 인접판례

최고법원 판례가 존재하지만 해당 카드의 직접 사실관계·쟁점이 아니라 인접 법리를 보강하는 데 사용된다.

### P3 — 인접·유사 판례

유사 법리나 사실관계를 보조적으로 사용한다. 직접 ratio처럼 서술하지 않는다.

### P4+ — 직접 판례 미축적, 인접법리·공식해석 존재

신설 법제에서 정상적으로 나타날 수 있는 등급이다.

### P4 — 법령·학설 중심

직접 판례를 억지로 채우지 않는다. 인공지능기본법 등 신설법에서는 P4가 품질결함을 의미하지 않는다.

### PN — 판례강도 비적용

법적 추론·논증 방법론 자체를 다루는 카드다.

## 5. 전수 적용

`data-source-article-citation-audit-20260809.js`가 `window.LEGAL_KNOWLEDGE`의 105개 모든 카드에 다음 값을 부여한다.

- `sourceAuditChecked`
- `sourceLinkGrade`
- `sourceLinkAudit`
- `articleAccuracyGrade`
- `articleAccuracyAudit`
- `precedentCitationGrade`
- `precedentCitationAudit`
- `citationAuditStage`

또한 런타임 집계 객체 `window.LEGAL_SOURCE_AUDIT_SUMMARY`를 생성하여 등급별 개수, C/D 출처 카드, 조문 C등급 카드, B1 취약경로 보유 카드를 추출할 수 있게 하였다.

이번 작업환경에서는 실제 브라우저의 최종 런타임 객체를 실행하여 정적 개수표를 고정하지 않았다. 따라서 문서에 임의의 등급별 카드 수를 적지 않는다. 등급 체계는 105개 전체에 적용되며 실제 화면 로딩 후 런타임 집계가 최종 수량의 기준이다.

## 6. 이번 감사에서 실제 교정한 사항

### 6.1 상표 유사·침해 카드 조문 재구성

`ip-trademark-similarity` 카드가 최종 correction 단계에서 상표법 제34조만을 직접 근거처럼 제시하고 있었다.

판례 `대법원 2020. 4. 29. 선고 2019후11121`은 등록무효 사건에서 상표법 제34조 제1항 제7호의 선등록상표 유사 여부를 판단한 판결이다. 반면 실제 상표권 침해행위의 법적 근거는 상표법 제108조가 직접 연결된다.

따라서 현재 카드는 다음 두 조문을 구별하여 병기한다.

- 상표법 제34조 제1항 제7호 — 선등록상표와 유사한 상표의 등록배제
- 상표법 제108조 — 침해로 보는 행위

이는 `등록가능성 판단`과 `등록 후 침해판단`을 한 조문으로 혼동하지 않기 위한 교정이다.

### 6.2 판례 직접링크 안정화

기존 8개 원문검증 판례 중 국가법령정보센터의 안정적인 `precInfoP` 직접링크를 확인할 수 있는 판례는 해당 링크를 우선하도록 변경하였다.

- 2023다232526 → 국가법령정보센터 `precSeq=606763`
- 2009다62059 → `precSeq=191093`
- 2019다280481 → `precSeq=234447`
- 2018후12004 → `precSeq=208793`
- 2019후11121 → `precSeq=226289`
- 2016후1710 → `precSeq=214413`

### 6.3 2024도4824의 공식 출처 유지

`대법원 2024. 9. 12. 선고 2024도4824` 사건은 대법원 공식 판례속보·보도자료가 피고인 1 부분을 파기환송한 것으로 확인된다.

국가법령정보센터의 검색 결과 중 동일 사건번호·선고일임에도 주문 표시가 공식 대법원 자료와 일치하지 않는 페이지가 확인되어, 이 사건에 대해서는 대법원 공식 판례속보를 주출처로 유지한다. 출처의 도메인 자체보다 해당 사건의 공식 원문·보도자료와 내용 일치성이 우선한다.

### 6.4 국토교통부 URL 안정화

자율주행자동차 영상정보 안전성 확보조치 관련 국토교통부 링크가 `idx`만 포함한 축약경로에서는 리디렉션 문제가 발생할 수 있어, 같은 공식 자료의 전체 쿼리형 정상 접근주소로 교체하였다.

### 6.5 MFDS URL 정규화

디지털의료제품 안전관리 시행계획의 식품의약품안전처 공식 주소를 정상 접근형 도메인으로 정규화하였다.

## 7. 링크 유효성의 의미

이 감사에서 105개 모든 URL을 외부 네트워크 요청으로 하나씩 HTTP 상태코드 검사했다는 의미는 아니다.

전수카드는 URL 구조·도메인·직접경로 유형을 자동 분류했고, 핵심 법령·판례 및 취약성이 의심된 공식 링크는 별도로 실제 웹 검색·열람을 통해 검증하였다. 법원 웹방화벽처럼 외부 크롤러 접근이 제한되는 링크는 `내용이 틀렸다`고 판정하지 않고 B1 안정성 주의로 분류한다.

따라서 출처감사는 다음 두 층으로 운영한다.

1. 전수 자동감사 — 105개 전체의 공식성·경로유형·조문직접성·판례강도 등급화
2. 수동 정밀감사 — C/D, B1, 조문 C, 판례 P1/P2 핵심 판결부터 공식 원문 대조

## 9. 운영 우선순위

향후 교정 순서는 다음으로 고정한다.

1. D — 오류 링크 즉시 수정
2. C — 보조자료만 있는 핵심 법적 주장에 공식 1차 출처 추가
3. B1 — 공식이나 불안정한 검색·뉴스 경로를 직접 고정링크로 교체
4. 조문 C → B/A — 카드의 주장과 직접 관련된 조문번호 확인
5. 조문 B/B+ → A/A- — 개별 조문 고정링크 정밀화
6. P1/P2 — 사실관계·ratio·판시범위 원문 대조 유지
7. P3/P4 — 필요할 때만 관련 판례를 추가하고 신설법에 존재하지 않는 판례를 만들어 넣지 않음

## 10. 결론

이번 감사의 목표는 모든 카드의 등급을 무조건 A/P1로 만드는 것이 아니다.

- 법령 직접근거가 핵심인 카드에는 정확한 조문이 우선이다.
- 판례형 카드에는 판결 원문과 ratio가 우선이다.
- 신설 AI 법제는 직접 판례가 없다는 사실을 정확히 표시하는 것이 더 높은 품질이다.
- 비교법·가이드라인은 국내법의 직접 법원과 명확히 구별한다.

105개 연구카드는 이제 내용밀도뿐 아니라 `출처의 권위`, `조문 직접성`, `판례의 인용강도`를 서로 독립된 품질지표로 관리한다.
