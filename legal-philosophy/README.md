# 법철학·기본권 연구

YEHAVHA NEXUS의 연구·지식 카테고리에 연결되는 독립 연구 아카이브입니다.

## 연구 목적

AI 행위효과와 민사책임 귀속, 기능적 단위의 제한적 법적 지위, 기본권·비례성, 권리·청구권, 정의론과 법적 논증에 직접 필요한 법철학 이론을 연구도구 형태로 축적합니다.

## 현재 구성

- 고전 정의론·자연법·사회계약
- 법실증주의와 법의 정당성
- 주관적 권리·청구권·기본권
- 법인격·법적 주체 이론
- 책임·귀속·교정적 정의
- 정의론과 기본적 자유
- 헌법상 비례성·형량
- 법적 해석·논증
- AI·다중 에이전트 시스템에 대한 적용

`data.js`의 `window.LEGAL_PHILOSOPHY` 배열에 항목을 추가하면 검색·필터·상세본문과 Nexus의 콘텐츠 수가 자동 갱신됩니다.

## Cloudflare Pages 최초 설정

프로젝트 이름: `yehavha-legal-philosophy`

Git 저장소: `yehavha2024-hash/yehavha-site`

프로덕션 브랜치: `main`

루트 디렉터리: `legal-philosophy`

빌드 명령: `exit 0`

빌드 출력 디렉터리: `.`

빌드 감시 경로 포함: `legal-philosophy/*`

자동 프로덕션 배포: 사용

예정 공개 주소: `https://yehavha-legal-philosophy.pages.dev/`

## 운영 원칙

법철학자의 생애를 나열하는 인물사전이 아니라, 핵심 명제·법적 개념·대표저작·현재 연구와의 연결을 중심으로 구성합니다. 실정법의 해석과 철학적 정당화는 구분하고, 논쟁적 이론은 특정 학설을 정답처럼 단정하지 않습니다.
